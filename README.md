
# Gene Expression Regulation Investigation

**Author:** P. Prathipa Sriji  
**Date:** June 2026  
**Platform:** PhET Interactive Simulations, University of Colorado  

## Project Overview

Independent virtual laboratory investigation into the molecular mechanisms regulating gene expression using interactive simulation technology.

## Objectives

- Investigate how transcription factors control protein synthesis
- Analyze RNA polymerase affinity effects on transcription rates
- Examine cellular variability in protein expression across populations

## Methods

- **Simulation:** Gene Expression Essentials (PhET)
- **Modules Used:** Expression, mRNA, Multiple Cells
- **Variables Tested:** 
  - Positive/Negative transcription factor concentration
  - RNA polymerase affinity
  - mRNA degradation rate
## Key Findings

| Condition | Result |
|-----------|--------|
| High Positive Transcription Factor | Increased protein output |
| Negative Transcription Factor | Blocked gene expression |
| High RNA Polymerase Affinity | Faster transcription initiation |
| Multiple Cells Simulation | Natural protein level variability |
